# Instructions for Codex

These instructions apply to the entire Salafis Day repository.

- Before planning, implementing, reviewing, or modifying this project, read the root `TRD.md` in full. Re-read it when it changes or its contents are no longer available in context.
- Follow the requirements, approved scope, technology decisions, constraints, and verification guidance in `TRD.md`.
- Respect the decision precedence defined in `TRD.md`, including the project owner's latest explicit instructions.
- Inspect the actual repository before claiming that a feature, dependency, migration, or deployment exists. The TRD describes requirements, not implementation status.
- Do not silently resolve decisions marked **TBD** or treat **Proposed** options as approved. Follow the TRD's decision process before introducing dependencies or changing architecture or scope.
- If `TRD.md` is missing or unreadable, tell the owner and request the document before proceeding with work that depends on its requirements.
